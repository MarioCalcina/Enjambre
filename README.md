# Enjambre

<img src="./assets/logo.svg" alt="Enjambre logo" width="64"/>

Torrent client for Windows, Linux, macOS, Android and iOS, with a built-in player to
watch videos while they download.

## Features

- Play video and audio files while they download, with `.srt` subtitles and audio track
  selection
- Pick which files of a torrent to download
- Organize torrents with labels, search, sort and filter them
- Share torrents as magnet links
- Speed limits and a limit on active downloads
- Keeps downloading in the background, and notifies when a download completes
- Light and dark themes; English, Spanish, French, Turkish and Chinese
- Built on [Transmission](https://transmissionbt.com) for low CPU and memory usage

## Installation

There are no published builds yet: build it yourself, see
[docs/development.md](./docs/development.md).

On Linux, `mpv` must be installed on your system. Other dependencies might be
required.
